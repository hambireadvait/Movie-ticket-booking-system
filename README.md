# Movie-ticket-booking-system
Movie Ticket Booking System 

A console-based Movie Ticket Booking System developed using the C programming language. This project allows users to register/login, book movie tickets, cancel bookings, and view booking history through a simple menu-driven interface.

Features

- User login and validation
- Ticket booking system
- Movie and show selection
- Automatic bill calculation
- Ticket cancellation
- Booking history management
- Input validation for name, phone number, and password

Technologies Used

- C Programming
- Structures
- Arrays
- Functions
- Loops and Conditional Statements

Concepts Implemented

- Structure handling
- Input validation
- Array management
- Menu-driven programming
- String handling
- Data storage using structures

Future Improvements

- File handling for permanent data storage
- Seat selection system
- Online payment integration
- Admin panel for movie management

This project is useful for beginners to understand the practical implementation of core C programming concepts through a real-world application.
